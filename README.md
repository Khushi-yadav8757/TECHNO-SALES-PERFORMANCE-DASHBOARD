# 📊 Techno Sales Performance Dashboard (Power BI)

🚀 This project is a Power BI dashboard developed as part of my **Hunar Internship Assignment** to analyze techno retail sales data and generate meaningful business insights.

The dashboard helps understand revenue trends, profit performance, brand contribution, category performance, and order status using interactive visualizations.

## 🧾 Project Overview

The Techno Sales Dashboard is designed to:
- Track overall sales performance
- Analyze brand-wise revenue
- Identify profitable product categories
- Monitor order & delivery status
- Visualize global sales distribution

This project focuses on turning raw data into actionable insights for business decision-making.

---

## 🎯 Objectives

- Understand business KPIs
- Perform sales & profit analysis
- Identify top-performing brands
- Analyze category-level performance
- Build an interactive Power BI dashboard

---

## 📈 Key Insights

- 💰 Total Revenue: **98.8M+**
- 📊 Total Profit: **22.8M**
- 📉 Profit Margin: **~23%**
- 🖥️ Top Revenue Brands: **Intel, Samsung, Dell**
- 📦 Top Profit Categories: **Monitors, CPUs, Graphic Cards**
